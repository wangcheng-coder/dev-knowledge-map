# Java 语言与类型

语言层确定数据怎么表示、名字怎么绑定、错误怎么传递。字节码和垃圾回收在 [JVM](jvm.md)。这里关注写出来的程序在进入虚拟机之前已经定下的合同。

## 类型与值

基本类型直接存数值。引用类型存的是指向对象的引用。方法传参传递的是值：基本类型传数值的副本，引用类型传引用这个值的副本。被调方法可以改对象里的字段，不能把调用方的变量改成指向另一个对象。

`String` 是不可变对象。拼接大量片段用 `StringBuilder`。文本和字节之间必须显式给出字符集，否则依赖平台默认编码。

包装类型带缓存和空值。整数比较和集合里要避免把「值相等」和「引用相等」混在一起。空引用是语言里的显式缺口，调用前要有所属关系：谁保证这个值已经准备好。

## 泛型擦除

泛型主要存在于编译期。运行时一个 `List<String>` 和 `List<Integer>` 都是 `List`，元素类型由编译器插入的检查和转换保证。因此不能直接 `new T()`，也不能用类型参数充当可具体化的数组类型。

反射能看到方法上还保留的泛型签名，那是额外写进字节码属性里的信息，数组元素本身仍然是擦除后的类型。

## 类、接口、包

类是状态和实现的单位。接口是一套可被多个类实现的方法合同。默认方法让接口可以带实现，冲突时按语言规定的优先级选择。

包用来组织名字。模块系统在包之上再加一层可读性：谁可以访问哪个包，依赖必须声明。大型程序用模块把内部包藏起来，库作者用它约束公开 API。

不可变数据优先用记录（record）。继承层次需要穷尽时用密封类，这样分支可以在编译期被检查是否写全。

## 初始化顺序

静态字段和静态初始化块在类初始化时按源码顺序执行，且只执行一次。实例字段初始化块在构造器之前、按书写顺序执行，父类先于子类。构造器里调用可被覆盖的方法，会在子类字段还没初始化时进入子类实现。生命周期相关的动作放到构造完成之后，或放到工厂里。

## 异常与资源

受检异常写在方法签名上，调用方必须处理或继续声明。运行时异常表示程序没有守住自己的前提。用来跨层传递业务结果时，选择一种项目里统一的方式，并保持边界处的转换。

实现了 `AutoCloseable` 的对象放进 try-with-resources。离开块时按声明的反序关闭，关闭抛出的异常会挂到主异常上。数据库连接、流和锁都按这个模式交还，避免依赖终结器。

## 集合的语言合同

`equals` 和 `hashCode` 必须一起成立：相等的对象哈希值相同。把可变对象放进 `HashMap` 的键之后再改参与哈希的字段，条目会找不到。`Comparable` 的顺序要和 `equals` 一致，有序集合才不会出现「比较相等但 equals 不相等」的条目。

具体容器的实现复杂度和并发行为见 [并发](concurrency.md) 与 OpenJDK 的 `java.util`。
