# 项目索引

这里按层汇总全文提到的仓库，方便跳转。角色分三类：

- 实现：这一层的生产代码，结论以它为准。
- 教学：规模可控，用来建立模型。
- 笔记：社区整理，用来检索关键词，再回到实现仓库核对。

## 维护

新增一行时写明角色、它属于哪一层、打开仓库后先看哪个目录。链接失效就删掉或改到新的官方地址，不保留跳转失败的入口。
